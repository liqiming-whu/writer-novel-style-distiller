# 证据、置信度与诚实边界

## 1. 证据类型

| 类型 | 说明 | 权重 |
|---|---|---|
| 全量统计 | 全部清洗正文的可复算指标 | 高，但只能证明形式分布 |
| 跨章精读 | 多个独立章节中同类机制复现 | 高 |
| 跨场景精读 | 日常、冲突、情绪等不同场景都成立 | 高 |
| 单章观察 | 某章明显出现 | 中低 |
| 自动启发式 | 脚本通过词表或标点推测 | 低，必须人工核验 |
| 设定／简介 | 对作品的外部说明 | 不能直接证明正文风格 |
| 读者评价 | 解释接受效果的二手证据 | 辅助，不替代文本 |

## 2. 置信度

### 高

同时满足：

- 至少三个独立文本位置。
- 至少两类场景。
- 早中晚没有明显反证，或漂移可解释。
- 能转换为具体写作动作。
- 有全量指标或强精读证据支持。

### 中

满足其一：

- 两个独立位置复现，机制清楚。
- 全量统计明显，但精读场景不足。
- 只在某类场景稳定出现，已经明确标注场景条件。

### 低

- 只见于单章、单人物或单卷。
- 依赖自动词表。
- 可能是题材惯例或剧情偶然。
- 样本不完整。

低置信观察不得写成“必须”“绝不”“始终”。

## 3. 冲突处理

- 时间漂移：分早期／中期／后期记录。
- 场景差异：分日常／行动／情绪／信息场景记录。
- 角色差异：放入角色声音矩阵。
- 无法解释：并列证据，标记待定，不强行调和。

## 4. 证据定位

优先格式：

`source_id / chapter_index / paragraph_hash / scene_type`

paragraph_hash 用清洗后段落的短 SHA-256 定位，不把整段原文复制进账本。必要短引控制在证明语言现象所需的最小范围。

## 5. 保真等级

- **A·高可信样本衍生**：全文或大样本覆盖，稳定核心证据充分，完成多场景测试和独立盲评。
- **B·可复用**：证据和静态校验完整，部分场景或盲评仍有限。
- **C·暂定**：样本偏少、漂移明显或只有局部章节。
- **D·不建议锁定**：清洗失败、来源混杂、结论互相冲突或无法区分角色声音。

没有执行独立盲评时，最高只能写“B·静态可复用”，不能宣称 A。

## 6. 诚实边界必须包含

- 样本范围与截止位置。
- 是否全文覆盖。
- 是否为翻译文本或多人文本。
- 哪些结论低置信。
- 哪些场景未覆盖。
- 是否执行独立盲评。
- 生成文风只能近似机制，不能复制作者创造力、生活经验和每句判断。
- 后续创作的项目事实和用户指令优先于样本文风。
