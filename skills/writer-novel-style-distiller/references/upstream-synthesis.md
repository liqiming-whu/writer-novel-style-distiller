# 上游项目调研与经验吸收说明

本 Skill 构建前已将以下仓库克隆到本地并阅读其主 Skill、关键参考文档、模板和脚本。下列提交号用于标记本次调研版本。

## 1. `zuoyou12/longzu.skillls` — `3f05bad`

许可证：MIT；许可证明确不覆盖所引用文学作品。

吸收的通用经验：

- 把共享叙事骨架与具体语言皮肤分开。
- 使用全文统计与精读采样共同校准。
- 短文本密度指标不可靠，硬失败与警告分级。
- 通过独立盲测验证辨识度，生成与评分分离。
- 重点防止“提纯式仿写”：笑点、格言、短句和口癖比原作更密。
- 记录语料边界，不把一个创作时期外推到作者全部作品。

本实现未复制其作者专属规则、语料统计值、盲测样本或文学作品片段。

## 2. `lvyu-cmd/chinese-novelist-skill` — `764a8ca`

仓库未发现明确 LICENSE 文件，因此只吸收抽象方法，不复制代码和大段文档。

吸收的通用经验：

- 阶段化流程、断点恢复和状态落盘。
- 限知视角、信息分层、对白潜台词、段落呼吸和多层校验。
- 修改层级从事实／设定到结构再到文字，避免润色暗改剧情。
- 使用脚本扫描套话、重复句式和段落问题。

修正与拒绝：

- 不采用固定感官数量、固定字数内冲突、固定波峰、固定爽虐比例等机械配额。
- 不把质检脚本当成文学判断本身。

## 3. `oscar-wang-xin/xin-skills` — `b358929`

仓库未发现明确 LICENSE 文件。README 声明只学文笔、不抄剧情。本实现没有复制其中 Skill 文本或示例。

吸收的通用经验：

- 从视角、句式、对白、节奏、词汇、情绪、钩子、环境、禁忌、开篇等维度形成可执行档案。
- 子风格比较能帮助识别不同类型的场景组件。
- 生成资产应包含允许／禁止清单与独立参考文件。

修正与拒绝：

- 不只分析开篇若干章，而采用全文统计与分层精读。
- 不把样本中未出现的所有手法自动列为绝对禁止。
- 不复制具体作品口癖、比例、人物结构和专属意象。

## 4. `alchaincyf/nuwa-skill` — `27642f5`

许可证：MIT。

吸收的通用经验：

- 调研／提炼／构建／验证的阶段分离。
- 观点或规则的复现性、生成力和排他性筛选。
- 保留矛盾，不强行调和。
- 诚实边界、信息不足降级和来源透明。
- 生成与独立评分分离，使用 Fidelity 报告。
- 自包含 Skill：参考资料必须位于 Skill 内部。

本实现将人物思想蒸馏方法改造成小说文风与读者依恋机制蒸馏，没有复制人物扮演模板。

## 5. `oscar-wang-xin/xin-novel-style-builder` — `aedd8b2`

许可证：MIT。

吸收的通用经验：

- 从小说文件到清洗、分析、模板、打包的端到端流程。
