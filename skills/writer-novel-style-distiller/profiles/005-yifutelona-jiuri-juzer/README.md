## 来源与状态边界

- 档案覆盖用户提供TXT中的全部现存文本，经人工复核恢复为378个语义章节，并选取26章进行分层精读。
- 章节范围为第1—379章，明确缺少第366章；用户说明该章因尺度问题被菠萝包下架，原章正文未提供。
- 第366章只登记用户概述及第367—369章可验证余波，不计入全文指标、文笔评分或直接场面精读。
- 作品按用户明确说明标记为未完结；路斯蒂娅成为实际亲密关系对象不等于最终伴侣，嫁人、百合或单身均不得提前确认。
- “伊芙人气很高”及第366章被部分读者视为毒点均为用户提供的接受经验；本档案不宣称已完成平台数据或外部读者接受史调查。
