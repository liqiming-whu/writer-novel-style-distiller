# 《伊芙特罗娜的旧日见闻》样本衍生文风执行卡

> 用途：在全新人物、全新世界和全新剧情中迁移抽象机制。
> 禁止：复制原作人物、专属名词、剧情、关系归宿、标志句或冒充橘赭Juzer本人。
> 状态：来源仍在连载；不迁移任何未经证实的最终伴侣或结局。

## 开写前五项检查

1. **当前焦点是谁？** 本场只贴近一个主要人物；需要换焦点时，先给段落、地点、事件或时间边界。
2. **眼前有什么具体事务？** 选择食物、衣物、工具、课程、交通、宠物、家务、工程或伤口中的一项作为场景抓手。
3. **宏大信息为何此刻进入？** 它必须回答人物的问题、改变关系或影响下一步行动。
4. **人物同时拥有什么公共形象与私人实况？** 两者都要真实，不能只靠误会制造笑点。
5. **本场最需要避免什么？** 专名倾倒、长句失控、全员同声、主角美貌围观或把亲密写成单方面宠爱。

## 正文中的十条核心动作

1. 用可见环境或正在进行的生活动作开场，不先贴设定说明。
2. 把视角压进焦点人物的即时判断，让其误解和知识边界保留。
3. 以具体物件触发历史、技术或制度信息；说明结束后必须回到物件和任务。
4. 长句只沿一条逻辑主链扩展；句群到达意义后，用短动作、短判断或对白落地。
5. 宏大议题落到谁会受伤、谁要付钱、谁来照顾、谁能选择以及明天怎样生活。
6. 关系通过共同事务增长：代劳、递物、等候、照顾、写信、共同学习或一起收拾残局。
7. 让主角有诚实无知、可见限制和会造成小后果的缺点，之后给修复动作。
8. 身体和衣物从角色主观感受进入，再写社会反应；美貌必须改变权力、欲望、风险或自我认识。
9. 幽默来自人格、身份落差和关系权限；真正触及伤亡、羞辱或拒绝时收敛。
10. 章末停在可见动作、关系余波、环境图景或改变下一步的问题上，不追加第二轮总结。

## 句段与节奏速查

- 以中长句为主，允许层递、插入和回环，但每段保留清楚主干。
- 单句段只用于定音、转折、惊讶或概念落点，不能连续滥用。
- 对白约占全文四分之一上下，只作宽容观察，不作字数配额。
- 信息章降低新专名数量；关系章提高动作与对白；战斗章缩短解释距离。
- 每出现一段高密说明，下一段优先回到人物身体、动作、对象或现场后果。
- 后期样本存在句段膨胀，迁移时应吸收其层次，不复制其冗长。

## 角色声音速查

### 好奇行动者

- 先承认不懂，再追问能影响决定的部分。
- 礼貌，但不是没有脾气；窘迫时会改口、否认、转移或一本正经反击。
- 真正关心别人时少说漂亮话，直接承担麻烦。

### 家庭照料者

- 从吃、睡、冷暖、钱和身体状况切入真正的话题。
- 玩笑建立在长期权限上；对方认真拒绝时必须收住。
- 拥有自己的家庭、欲望和疲倦，不是万能母亲。

### 追随者／守护者

- 忠诚可以极端，但必须有个人罪责、信念、判断和会拒绝的底线。
- 不把每句话都写成赞美，不把每次行动都变成舍命保护。

### 学者／长生者

- 先问前提，再给不完全答案。
- 观点受个人经历和时代位置限制，不能代表作者全知真理。
- 在生活习惯上保留怪癖、疲倦、偏见或幽默。

### 权力人物

- 表层谈礼貌与程序，真实目的通过称呼、停顿、第三方和交换条件进入。
- 不把利益计算写成数据报告；让人物有所隐瞒，也可能误判。

## 主角魅力执行卡

### 必须保留的组合

- 高学习力＋真实知识边界。
- 能力＋失败／疲倦／代价。
- 脆弱＋下一步行动。
- 公共形象＋私人生活纹理。
- 关心别人＋允许别人拒绝。
- 小缺点＋真实后果＋修复。
- 身体魅力＋主体感受＋选择边界。
- 同性／异性可能＋不预设归宿。

### 每场只选一到两项

不要同时堆叠嘴馋、贪杯、脸红、迷糊、换衣、被夸、全员保护和惊人战力。可爱必须随场景变化，也必须让其他角色像完整的人。

### 造神降噪

- 少写“所有人都惊呆了”，多写某个具体人物因自身利益或经历产生反应。
- 少让旁白宣布善良，改写主角承担别人看不到的小麻烦。
- 让配角批评、拒绝、误解或不原谅主角。
- 让主角在专业问题上求助，让别人的能力真实改变结果。

## 百合与婚姻边界

1. 女性友谊、同性欲望和最终伴侣是不同层级，不互相替代。
2. 已有好感可以矛盾、退缩和推进，但不能用题材标签跳过人物选择。
3. 男性追求者存在不等于嫁人；讨论丈夫与孩子也不等于主角想要婚姻。
4. 保持单身同样需要由欲望、价值与行动推导，不能只因关系线未写完。
5. 首次性经验是高权重关系节点：对象、铺垫、动机、同意与事后变化必须互相对应；若故意改道到新角色，需要让改道揭示人物，而不是只制造刺激。
6. 醉酒、秘密暴露、身份差和“半推半就”都会削弱同意清晰度；后续主动亲吻或继续交往不能倒推此前施压天然合理。
7. “清白／好女孩”是可能存在的读者接受语言，不是衡量女性人格价值的客观标准；审计应落在能动性、责任和关系连续性。
8. 来源作品未完；路斯蒂娅是实际性关系对象却仍非确定终局，后续创作不得借此档案宣称伊芙或任何仿生角色的既定伴侣。

## 高风险AI套话与穿帮项

### 通用套话

- 嘴角勾起、眼底掠过、空气凝固、命运齿轮、无人知晓。
- 连续使用“仿佛／好似／如同”却不给喻体的认知来源。
- 用“她很善良／聪明／特别”代替行为与后果。
- 每个角色都能立刻说出完整、漂亮、正确的观点。

### 本档案专属穿帮

- 把华丽繁复误写成形容词和比喻堆砌。
- 让每场都插入文明史、技术史或人生哲学。
- 让主角永远是房间里最漂亮、最聪明、最善良的人，并让所有人公开认证。
- 把变身角色当前女性身份写成永久伪装。
- 用身体羞怯代替性别成长，用旁人凝视代替身体主体性。
- 把首次性关系当作可随意分配的路线奖品，跳过长期铺垫、明确同意与事后责任。
- 用“她后来也主动了”消除早先醉酒、秘密压力或权力差，也不区分争议接受与客观人格评价。
- 把黑色幽默对准死者、弱者和创伤本身。
- 擅自复制伊芙、雨切、南芬、艾琳德、路斯蒂娅及原作专属关系。

## 写后检查

- [ ] 焦点人物的知识来源清楚，未读取叙述者或他人脑内信息。
- [ ] 场景有当前任务，不只是高密描写或设定展示。
- [ ] 每段说明都改变了理解、关系或下一步行动。
- [ ] 长句有主干，短句承担了真实落点。
- [ ] 宏大议题最终回到了具体人物与生活后果。
- [ ] 对白能凭措辞、称呼和目的区分人物，而非全员同声。
- [ ] 主角可爱来自行为组合，不是全员宠爱与旁白认证。
- [ ] 身体、性别和欲望保留主体选择，没有固定终局先验。
- [ ] 亲密节点写清了双方选择、拒绝空间、权力差和事后变化；没有用醉酒或半推半就代替同意。
- [ ] 若关系路线突然改道，改道揭示了人物并承担预期成本，不只是刺激读者。
- [ ] 幽默没有消除伤亡、拒绝或权力伤害的后果。
- [ ] 结尾停在动作、余波、图景或问题，没有解释两遍。
- [ ] 未复制原作专属人物、剧情、名词、关系归宿或标志句。
