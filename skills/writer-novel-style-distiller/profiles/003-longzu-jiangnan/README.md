# 003 · 《龙族1—4》样本衍生文风档案

这是 `writer-novel-style-distiller` 内置的第三个可复用档案。

## 内容

- [完整文风操作系统、文笔量化审计与幽默感审计](style-profile.md)
- [快速执行卡](application-card.md)
- [路明非代入机制与楚子航、绘梨衣角色魅力](protagonist-charm.md)
- [四个卷级尾声与连载收束设计参考](ending-design.md)
- [证据账本](evidence-ledger.md)
- [公开来源与覆盖清单](source-manifest.json)

## 适用方式

- 写作、改写或比较文笔时，先读 `style-profile.md` 与 `application-card.md`。
- 设计代入型普通人主角，或分析楚子航、绘梨衣式角色依恋时，再读 `protagonist-charm.md`。
- 设计长篇分卷收束、卷级余波或连载钩子时，再读 `ending-design.md`。
- 需要解释结论、检查证据或确认四卷与前传的边界时，读 `evidence-ledger.md` 与 `source-manifest.json`。

## 来源与状态边界

- 主档案覆盖《龙族》卷一至卷四，共四个主卷尾声；卷三纸质版上中下合并为同个叙事卷。
- 合订本所含《哀悼之翼》作为辅助前传登记，不并入四卷文笔评分。
- 系列按未完结处理；档案只分析章节、场景和卷级收束，不宣称已经分析全书最终结局。
- 路明非按读者代入／投射机制分析；楚子航和绘梨衣按高人气角色的文本机制分析。现实人气判断来自用户，本档案未执行外部读者接受史调查。
