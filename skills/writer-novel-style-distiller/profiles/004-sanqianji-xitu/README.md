## 适用方式

- 写作、改写或比较文笔时，先读 `style-profile.md` 与 `application-card.md`。
- 设计身份重建、变身身体经验、创伤后复苏或慢热女性关系时，再读 `protagonist-charm.md`。
- 设计终卷、结局、尾声或番外时必须先读 `ending-design.md`，并遵守“来源未完结、不得外推原作结局”的边界。
- 解释评分、检查证据和核对格林／月儿兰身份连续性时，读 `evidence-ledger.md` 与 `source-manifest.json`。

## 来源与状态边界

- 档案覆盖用户提供TXT中的全部现存内容，经人工复核划分为53个语义单元，并选取40个单元进行分层精读。
- 源文件章号存在跳缺；前置六章未见正式总标题，档案使用描述性临时名称，不虚构缺失章节。
- 作品按用户明确说明标记为未完结；第一卷卷末不是全书结局。
- 《斯巴达斯特隘口的红土》按战争插篇登记；《炼狱外篇之亚克传（一、誓言）》按现存外篇登记，二者均不替代主线终局。
- “月儿兰多年后仍令人念念不忘”是用户提供的接受经验；本档案解释文本机制，不宣称已完成外部读者接受史调查。
