# 《有匪》样本衍生文风执行卡

## 开写前

1. 当前任务是新写、续写、扩写还是改写？边界在哪里？
2. 当前焦点人物是谁？他掌握的信息从何而来？
3. 当前场景属于日常、关系、行动、情绪还是信息模式？
4. 本场最重要的选择、关系变化或代价是什么？
5. 哪个高频指纹本场必须克制：机锋、长句、反差、自嘲还是比喻？

## 条件加载

- 设计核心主角魅力时读取 [protagonist-charm.md](protagonist-charm.md)。
- 设计终卷、最终高潮、结局、尾声或番外前读取 [ending-design.md](ending-design.md)。
- 结局设计只迁移承诺回收、选择与代价、情绪降落等机制，不复制原作事件和归宿。

## 正文执行

1. 使用第三人称限知，连续场景只贴近当前焦点人物。
2. 心理直接融入叙述，少写“他想”“她觉得”。
3. 中长句串联动作、观察与判断，关键处用短句定音。
4. 对白独立成段，对白之间插入行动和人物化观察。
5. 情绪先落在动作、回避、称呼和选择上，读者已经明白时停止解释。
6. 玩笑必须来自人物性格和处境，不能让全员共享同种机锋。
7. 战斗先写空间、目标和限制；招式只有改变局势时才展开。
8. 信息先给物证、称呼或异常反应，再允许人物猜错，最后由行动确认。
9. 强者以克制、判断和承担后果证明能力，不靠配角齐声赞叹。
10. 高潮之后回到行动、日常或沉默，让情绪自行沉降。

## 分场景调度

| 场景 | 主要动作 | 应克制 |
|---|---|---|
| 日常 | 用事务制造关系摩擦和笑点 | 无效闲聊、连续抖梗 |
| 亲密 | 台词回避，行动诚实；用称呼和共享秘密推进 | 直白总结感情、单向照顾 |
| 战斗 | 明确争夺目标、站位、分工与代价 | 招式清单、旁观者吹捧 |
| 悲伤 | 维持原动作，再让细节暴露失败 | 情绪标签、泪点解释 |
| 信息 | 锚点—误判—裂缝—确认 | 旁白倾倒、角色超游 |
| 结局 | 承诺—最终选择—多层闭环—余波—停止点 | 临时神迹、清单式交代 |
| 番外 | 每篇只承担明确新增功能 | 重复主结局、替主线补核心欠账 |

## 角色声音速查

- **机锋型**：自嘲与玩笑降低威胁；真正紧张时反而短暂词穷或突然认真。
- **行动型**：台词短，先做后说；情绪从停顿、称呼和补救动作泄露。
- **权威型**：命令简短，控制失准时话语变长或转为制度辩解。
- **谋略型**：说话留余地，把个人愿望藏进大局和安排。

## 穿帮警报

- 是否写出了当前人物不可能知道的真相？
- 是否所有角色都变得伶牙俐齿？
- 是否用“嘴角微勾、眸光一沉”等通用反应替代具体动作？
- 是否把克制写成没有情绪？
- 是否把长句写成无中心的定语堆砌？
- 是否靠反复受伤、昏迷和照顾制造男主魅力？
- 是否为了圆满结局临时投放解药、援军或隐藏血统？
- 是否把配角和番外当成替主角收拾欠账的工具？

## 写后检查

- 视角是否稳定，情报来源是否成立？
- 每段对白是否能辨认说话者的关系目的？
- 情绪是否已经被行动表现，却又被旁白重复解释？
- 日常是否承载伏笔、能力或关系变化？
- 高潮中的援助是否有旧线索与人物关系支撑？
- 结局是否兑现核心承诺，同时保留恰当余味？
- 删除尾声或番外后，主线是否仍然自足？
- 是否迁移了结构机制，而非改名复制原作？

## 优先级

当前用户指令 > 项目事实与连续性 > 当前场景目标 > 本执行卡 > 样本统计。
